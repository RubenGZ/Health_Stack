Variables y funciones en window.* de uso transversal. Todos los módulos pueden acceder a estos sin importar.

window.navigateTo(section) Navega a una sección de la SPA. Actualiza URL hash, activa la sección, emite hs:section-changed. Definido en: app.js
window.apiFetch(url, opts) Wrapper de fetch con JWT Bearer, refresh automático (401), timeout, error normalizado. Úsalo en vez de fetch() directamente. Definido en: api.js
window.t(key, params?) Traduce una clave i18n. Soporta interpolación {{var}}. Retorna la clave si no existe traducción. Definido en: i18n.js
window.showToast(msg, type?) Muestra un toast. type: 'success' | 'error' | 'info' | 'warning'. Reemplaza alert(). Definido en: toast.js
window.showConfirm(msg, opts) Diálogo de confirmación async. Retorna Promise<boolean>. Reemplaza confirm(). Definido en: toast.js
window.setFieldState(input, state, msg?) Aplica estado visual a un campo de formulario. state: 'error' | 'success' | 'loading' | null. CSS classes en el parent .field-wrap. Definido en: app.js
window.createEmptyState(icon, title, desc) Genera HTML de estado vacío premium (icono + título + descripción). Insertar con innerHTML. Definido en: app.js
window.createSkeletonCard(count?) Genera N skeleton cards animadas (shimmer CSS). Insertar mientras carga datos async. Definido en: app.js
window.haptic(type) Dispara vibración haptic. type: 'light' (10ms) | 'medium' (25ms) | 'heavy' (50ms) | 'success' (patrón doble). No-op en desktop. Definido en: app.js
window.Dashboard API pública del dashboard. { init(), refresh(), updateStreak(), renderProgressInsight() }. Cargado por js/dashboard/index.js (Fase 5). Definido en: js/dashboard/index.js
window.PWAManager Gestión PWA. { init() }. Maneja beforeinstallprompt y iOS Safari. Cargado por js/pwa/index.js (Fase 5). Definido en: js/pwa/index.js
window.HS_CONFIG Configuración de app. { API_BASE, SPONSOR, VERSION, ... }. Inmutable en runtime. Definido en: config.js

Patrón de módulos

IIFE Módulo clásico

La mayoría de los 60 archivos. Se ejecuta inmediatamente, puede exponer un objeto en window.* o ser autocontenido. Compatible con <script defer>.

(function () {
  'use strict';
  function _init() { ... }
  window.MyModule = { init: _init };
})();

ESM ES Module

Usado en el árbol de workout: workoutInit.js, workoutSession.js, workoutPR.js, oneRepMax.js, athleteViewer.js. Requiere type="module". No accesibles desde IIFEs sin puente.

// workoutInit.js
import './workoutSession.js';
import './workoutLogger.js';
import './workoutPR.js';
